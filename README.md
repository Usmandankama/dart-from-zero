# Dart from Zero

The code for the course Dart from Zero on PadiLearn.

There's one folder per lesson. Each one has:

- the lesson's examples, exactly as they appear in the video
- `exercises.dart`: practice to try yourself
- `solutions.dart`: one way to answer each exercise

Lesson 1 has no code, so the folders start at lesson 2.

## Run the code

Install Dart (lesson 2 shows you how), download this code, open a terminal in this folder and type:

```
dart run lesson_03_variables/variables.dart
```

Change the path to run any other file.

## Get the most from it

Type the code yourself as you follow along. Pause the video as often as you need. Try each exercise before you open its solution: making mistakes and fixing them is how it gets into your head.

If the ₦ sign shows up as a strange character in your terminal, run `chcp 65001` once in that terminal and try again.

## After this course

Advanced Dart carries on with exceptions, async, files, packages and tests, and then builds a complete program with all of them.
